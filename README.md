# ClimateScope Dashboard (Milestone 3)

## How to Run the Dashboard

1. Make sure you have Python 3.8+ installed.
2. Place your weather data file at:
   - `data/weather_cleaned.csv`
3. Start the dashboard:

```powershell
streamlit run task3/dashboard_m3.py
```

4. Open the browser at the URL shown (usually http://localhost:8502).
